# Экспериментальный стенд Deskhand · ПР3 и ПР4

**Авторы:** Павлов Александр, Бобрусь Александр.

## Быстрый запуск

Нужны Git, Make, Python 3 и запущенный Docker с Compose v2. Для первой сборки нужен интернет.

```sh
git clone https://github.com/BobrAll/pyweb3-4.git
cd pyweb3-4
make experiment
```

В сводке `results/processed/main/table.md`, которая появится после запуска, каждая строка соответствует одному сочетанию длины истории и размера дерева. `Full bytes` и `Bounded bytes` — медианные объёмы данных за всю траекторию для полной и сокращённой истории. `Reduction %` показывает, на сколько процентов сократился объём, а `95% CI` — доверительный интервал этой оценки.

В той же папке находятся графики и `summary.json` с результатами контроля A/A и проверок сохранности. Сырые показатели каждого шага и манифесты запусков появятся в `results/raw/main/`.

В проведённом эксперименте сокращение составило **56,64–91,05%**. Проверки сохранности актуальных наблюдений прошли во всех прогонах. Стенд измеряет объём синтетической истории. Для оценки скорости и успешности агента в macOS нужны отдельные измерения.

## Дополнительные команды

| Команда | Что выполняется |
|---|---|
| `make smoke` | Тесты и 20 контрольных прогонов сокращённого плана |
| `make experiment BATCH=review` | 120 основных и 10 A/A-прогонов в новой папке |
| `make analyze BATCH=review` | Повторный анализ сохранённых измерений |
| `make down` | Остановка ресурсов Compose |

Для повторного запуска задайте новое имя `BATCH`: существующие данные защищены от перезаписи. При одинаковом конфиге и окружении объёмы и проверки должны совпасть точно. Время зависит от машины. Для анализа опубликованных измерений распакуйте архив в свежей копии репозитория и выполните `make build && make analyze BATCH=main`.

Параметры задаёт [конфигурация эксперимента](configs/experiment.json). Стенд запускает каждый прогон в новом процессе, исключает два прогревочных прохода и перемешивает порядок по фиксированному seed. Контейнеры ограничены 2 CPU и 1 ГиБ памяти и работают без сети. GitHub Actions запускает сокращённый план и сохраняет его результаты.

Стенд использует [Python-порт алгоритма Deskhand](vendor/deskhand/README.md) с фиксированной ревизии. Политика `bounded` оставляет последние деревья трёх приложений, последнее сообщение со снимком и последний блок изменений. Сверку с исходным Swift-фрагментом можно повторить командой `python3 -m scripts.check_swift_parity` при установленном компиляторе Swift. [Схема стенда](docs/architecture.md).

Редактируемые версии отчётов — [ПР3](docs/pr3-report.md) и [ПР4](docs/pr4-report.md). Для пересборки PDF запустите `python3 scripts/build_reports.py` с установленным ReportLab и шрифтом Arial или DejaVu Sans.
